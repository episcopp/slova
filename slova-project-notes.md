# Слова — тренажер італійської (проєкт)

**Файл:** `slova-project-notes.md`
**Дата останньої правки:** 2026-11-15 (версія застосунку 1.4)

## Мета проєкту
Власний Duolingo-подібний тренажер слів для Данила (рівень ~A2, італійська). Один файл `index.html` на GitHub Pages (`https://episcopp.github.io/slova/`), синхронізація між пристроями через Firebase (Auth + Firestore), безкоштовно. Встановлюється на iPhone через «На початковий екран».

## Що є і працює (перевірено автотестами, jsdom)
- Імпорт слів: вставка тексту, PDF, txt/csv. Дублікати пропускаються.
- Урок із 10 слів, режими «Говорити» (розпізнавання мовлення) і «Писати».
- Кнопка «Не знаю» — показує відповідь і повертає слово в чергу.
- Дієвідмінювання (Presente, Futuro, Passato prossimo, мікс): рушій написаний вручну, ~40 неправильних дієслів.
- Темна/світла тема, стиль Duolingo, свої іконки.
- Звуки правильно/неправильно (синтезовані), перемикач звуку.
- Кнопка «Перевірити» піднімається над клавіатурою з анімацією.
- Синхронізація Firebase: окремі акаунти, злиття за «надгробками» видалених слів.
- Озвучка: голоси браузера, Azure Neural (безкоштовно до 500k символів/міс.), ElevenLabs (платно). Ключі зберігаються лише на пристрої.
- **Нове:** екран «Слово за хвилину» (відкривається з параметрів `?notif=1&…`): слово, поле вводу з автофокусом, перевірка, конфетті при правильній відповіді, червоний колір + «тряска» при помилці, оновлення рівня слова й серії, автоповернення на головну через ~2,2 с.
- **Нове:** екран «🔔 Нагадування» (ввімкнення/вимкнення пушів, ввід VAPID-ключа).
- **Нове:** `firebase-messaging-sw.js` (приймає пуш у фоні, по тапу відкриває слово).
- **Нове:** GitHub Actions `hourly-word.yml` + `scripts/send-hourly-word.js` — щогодини шлють випадкове слово користувача. Логіку скрипта перевірено на підробленому firebase-admin (відправка, пропуск, видалення недійсного токена).

## Що не працює / обмеження
- **Ввід відповіді прямо всередині банера сповіщення та анімація в ньому — неможливі для веб-застосунку** (потрібен нативний iOS-застосунок на Mac з Xcode; без оплати — лише з перевстановленням кожні 7 днів, або $99/рік). Від цього відмовились.
- **Віджет, що зникає після відповіді** — також лише нативний. Не робимо.
- Пуші на iPhone працюють тільки якщо застосунок додано на головний екран і відкрито звідти (iOS 16.4+).
- Реальна доставка пуша на телефон і запуск GitHub Actions **ще не перевірялись** (з пісочниці це неможливо) — потрібне тестування на твоєму iPhone.
- Розпізнавання мовлення залежить від браузера (Chrome/Edge надійніше; на iPhone — обмежено).
- Кнопка над клавіатурою на iPhone зі сторонньою клавіатурою може бути трохи низько (`IOS_KB_EXTRA=44` у коді — можна збільшити).
- Імпорт із PDF інколи додає сміттєві рядки — видаляються вручну в «Мої слова».
- GitHub Actions за розкладом може запускатись із затримкою кілька хвилин.

## Налаштування нагадувань (одноразово, безкоштовно)
1. У Firebase Console → Project settings → вставити повний блок `firebaseConfig` у застосунку (Синхронізація → «Змінити налаштування Firebase»), щоб підхопились `messagingSenderId` і `appId`.
2. Project settings → Cloud Messaging → Web Push certificates → **Generate key pair** → скопіювати ключ (VAPID).
3. Project settings → Service accounts → **Generate new private key** → завантажиться JSON. Нікому не показувати й не додавати в репозиторій.
4. GitHub → репозиторій `slova` → Settings → Secrets and variables → Actions → New secret: ім'я `FIREBASE_SERVICE_ACCOUNT`, значення — весь вміст JSON.
5. Завантажити в репозиторій: оновлений `index.html`, `firebase-messaging-sw.js`, папки `.github/workflows/` і `scripts/` (зі збереженням шляхів).
6. Відкрити застосунок з головного екрана iPhone → «🔔 Нагадування» → вставити VAPID → дозволити сповіщення.
7. Перевірка: GitHub → Actions → Hourly word notification → Run workflow.
